Answer:
Harvard Architecture is suitable for an embedded system. It has separate memory spaces and buses for instructions and data, allowing the CPU to access instructions and data simultaneously. This provides faster and more efficient processing and is commonly used in embedded and real-time applications. � � CA UNIT 1.pdf CA UNIT 1.pdf

2. Explain the difference between CISC and RISC architectures.
Answer:

RISC: Uses a small set of simple instructions, simple addressing modes and generally executes an instruction in a single clock cycle. CISC: Uses complex instructions, complex addressing modes and an instruction may require more than one clock cycle. RISC uses more registers and fixed-size instructions, while CISC uses fewer registers and variable-size instructions. � � CA UNIT 1.pdf CA UNIT 1.pdf
