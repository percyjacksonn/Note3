UNIT I – Introduction to Microprocessors, Microcontrollers and Architectures

These answers are prepared in simple, student-friendly language, suitable for writing in Anna University examinations.

1. Define a microprocessor.

A microprocessor is a programmable electronic device that acts as the CPU of a computer system. It performs arithmetic, logical and control operations based on instructions given to it.

2. Define a microcontroller.

A microcontroller is a single-chip computer that contains a CPU, memory (RAM and ROM) and input/output (I/O) ports. It is mainly used in embedded systems.

3. Differentiate between a microprocessor and a microcontroller.

Requires external memory and peripherals.Most components are available on a single chip.

4. Define an interrupt.

An interrupt is a signal that temporarily stops the normal execution of a program and makes the processor execute a special routine called the Interrupt Service Routine (ISR).

5. What is the function of the Program Counter?

The Program Counter (PC) is a special register that stores the address of the next instruction to be executed by the processor.

6. What is the function of the Stack Pointer?

The Stack Pointer (SP) is a special register that holds the address of the top of the stack in memory. It is used during subroutine calls, returns and interrupt handling.

7. Define an opcode and an operand.

  • Opcode: Specifies the operation to be performed by the processor.
  • Operand: Specifies the data or address on which the operation is performed.

Example: In ADD A, B, ADD is the opcode and A, B are the operands.

8. What is meant by instruction execution cycle?

The instruction execution cycle is the sequence of steps performed by a processor to execute an instruction.

It consists of three main stages:

  1. Fetch: Retrieves the instruction from memory.
  2. Decode: Identifies the operation to be performed.
  3. Execute: Performs the specified operation.

UNIT II – 8086 Microprocessor Architecture and Programming

1. What is a 16-bit microprocessor?

A 16-bit microprocessor is a processor that can process 16 bits of data at a time. It has 16-bit registers and an ALU to perform arithmetic and logical operations.

Example: Intel 8086 microprocessor.

2. List the important features of the 8086 microprocessor.

The important features of the 8086 microprocessor are:

  1. It is a 16-bit microprocessor.
  2. It has a 20-bit address bus.
  3. It can address up to 1 MB of memory.
  4. It has a 16-bit data bus.
  5. It has a 6-byte instruction queue.
  6. It supports pipelining.
  7. It operates in minimum and maximum modes.

3. Draw the block diagram of the 8086 microprocessor.

The 8086 microprocessor consists of two major functional units:

  1. Bus Interface Unit (BIU).
  2. Execution Unit (EU).

4. What is a Bus Interface Unit (BIU)?

The Bus Interface Unit (BIU) handles all bus operations such as instruction fetching, memory reading, memory writing and address generation. It also contains a 6-byte instruction queue.

5. What is an Execution Unit (EU)?

The Execution Unit (EU) decodes and executes instructions. It contains the ALU, control unit, general-purpose registers and flag register.

6. What is pipelining?

Pipelining is a technique in which instruction fetching and instruction execution are performed simultaneously to increase the speed of the processor.

7. What is an addressing mode?

An addressing mode specifies the way in which the operand is accessed or the location of the data required by an instruction.

9. Define an assembler.

An assembler is a system software that converts an assembly language program into machine language (object code) that can be executed by the processor.

10. What is an assembly language program?

An assembly language program is a set of instructions written using mnemonic codes and symbolic addresses to perform a specific task.

Examples: MOV, ADD, SUB and JMP.

12. What is a flag register?

The flag register is a 16-bit register that indicates the status of the result of arithmetic and logical operations and controls certain processor operations.

Examples of flags:

  • Carry Flag (CF)
  • Zero Flag (ZF)
  • Sign Flag (SF)
  • Overflow Flag (OF)
  • Parity Flag (PF)

13. What is meant by minimum mode and maximum mode in 8086?

Minimum Mode: The 8086 operates in a single-processor system and generates control signals directly.

Maximum Mode: The 8086 operates in a multiprocessor system and uses an external bus controller (8288) to generate control signals.
